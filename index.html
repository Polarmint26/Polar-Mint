Backup

Esporta backup

Scarica un file con tutti i dati del gestionale: ordini, DDT, clienti, prodotti, imballi, magazzino, fornitori, trasportatori e i documenti allegati.

Conservalo su un disco, una chiavetta o un NAS aziendale.

Esporta anagrafiche in Excel

Scarica un file Excel con clienti, destinazioni, listini, prodotti, formati di imballo, imballi, fornitori, prezzi fornitori e trasportatori, un foglio per ciascuno.

Utile per controllare i dati o per importarli in un altro gestionale.

Importa backup

Ricarica i dati da un file di backup esportato in precedenza, anche su un altro computer.

Attenzione: i dati attuali vengono sostituiti da quelli del backup.
